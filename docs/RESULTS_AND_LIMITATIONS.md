# 結果與限制

## U-Net

專題記錄的五折平均 **Pixel Accuracy 為 97.77% ± 0.33%**。這是每個像素分類正確的比例，不等同 Dice、IoU 或空穴面積誤差。背景比例較高時，單看 Pixel Accuracy 可能無法完整反映目標區域分割品質。

U-Net 版本與訓練程式集中在 [BioUS-Net](https://github.com/tsengwt1210/BioUS-Net)。本庫保留一份整合時期的腳本；本次整理沒有重跑五折訓練，也沒有以目前腳本宣稱重現該數字。舊 README 與競賽說明中的單次 97.54% 不作為五折整體結果。

## BPNN

既有《倒傳遞神經網路_面積預測分析報告_0806-final》記錄了不同能量、特徵與隱藏層組合的比較。報告中有兩種需要分開的結果：

1. 架構搜尋曾記錄 0.8J、`[9,40]` 的低誤差結果；後續重訓未穩定重現原本的最低值。
2. 保存供後續使用的 0.8J 模型採 `[5,3,2]`，報告記錄的**正規化面積最佳驗證 MSE 為 5.0596 × 10⁻⁶**。

原文件部分敘述將 MSE 寫為「均方根誤差」；本庫統一使用 MSE。這個值沒有開根號，也不是獨立測試集的面積誤差。模型保存檔不含訓練紀錄，因此目前能核對結構與推論，無法只憑 `.mat` 重建最佳驗證數字或當次資料切分。

### 資料切分的限制

每種能量只有五組不同的輸入特徵，每組對應五次面積量測。歷史流程先展開成 25 筆，再以 `dividerand` 分割；同一組特徵的重複量測可能分散至訓練與驗證／測試子集。

因此，歷史驗證誤差主要反映這批實驗資料的擬合情況，不能直接證明對新特徵組、新測試片或新設備的泛化能力。若重新設計評估，應依實驗組別切分，保留未參與模型選擇的資料，並回報還原至 mm² 後的誤差。

## 面積與信心度

手動畫多邊形使用 `polyarea`；U-Net 遮罩可計算前景像素數；Mask R-CNN 接口使用 `cv2.contourArea` 計算外輪廓面積。這些面積定義並不完全相同，比較前需先統一校正與處理方式。

影像面積換算需要有效的 `mm/pixel` 比例尺。模型顯示的 confidence 是模型分數，不是物理量測的不確定度，也不能直接視為分割正確率。

## 尚未驗證的範圍

- 新設備、不同測試片材質或不同倍率下的泛化能力。
- 臨床超音波影像、病患資料或治療效果預測。
- 三種分割方法在相同資料切分、相同面積定義下的完整比較。
- MedSAM 的正式定量優劣比較；初期探索與後續微調、自動流程需各自記錄。
- 下載本庫後，連接特定攝影機、Arduino 和外部權重的完整 GUI 操作。

本次程式檢查與歷史實驗結果分開記錄，詳見[驗證紀錄](VALIDATION.md)。
